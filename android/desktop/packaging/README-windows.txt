VTLO 3O3 for Windows

Double-click "VTLO 3O3.exe". No installation needed; the Java runtime is
included. Your patterns and samples are saved in %APPDATA%\VTLO 3O3.

Seven screens: BASS 1, BASS 2, WOBBLE, DRUMS 1, DRUMS 2, SAMPLER, FX.
Keys: Space run/stop, Tab next screen (F1-F7 jump), Esc panic.
SET loads a live set (UK drum and bass, hardtekno tribe); the pads 1-4 on the
top bar, or Alt+1..8, change scene on every instrument together.
Bass lines and WOBBLE: Z S X D C V G B H N J M , play the keyboard.
Sampler: Q W E R / A S D F play pads 1-8.
Right-click a step: gate (bass) or accent (drums, sampler).
Knobs: drag up/down or use the mouse wheel; double-click resets.
